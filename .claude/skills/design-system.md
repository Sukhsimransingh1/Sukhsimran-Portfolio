# Design System

Use an 8px spacing system.

Typography drives the design.

Everything should align to a responsive grid.

Never hardcode spacing randomly.

---

## Components

Every component must be reusable.

No duplicate UI.

Prefer composition over repetition.

---

## Cards

No generic glassmorphism.

Cards should feel clean and architectural.

---

## Buttons

Minimal.

Elegant.

Strong hover states.

Accessible.

---

## Typography

Large display headings.

Readable body text.

Comfortable spacing.

Consistent hierarchy.

---

## Colors

Use semantic tokens.

Never hardcode colors.

Prepare support for light and dark themes.

Accent colors must be used sparingly.

---

## Accessibility

WCAG friendly.

Keyboard navigation.

Semantic HTML.

Reduced motion support.

ARIA labels.

---

## Responsive

Desktop first.

Then tablet.

Then mobile.

No layout should break.
