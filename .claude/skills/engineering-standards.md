# Engineering Standards

Code should be production-ready.

Readable.

Maintainable.

Scalable.

Well documented.

---

Use:

Strong typing.

Reusable hooks.

Reusable utilities.

Meaningful naming.

No magic numbers.

No duplicated code.

No unnecessary dependencies.

---

Performance

Optimize images.

Lazy load components.

Avoid unnecessary re-renders.

Optimize fonts.

---

Accessibility

Semantic HTML.

Keyboard support.

Focus states.

ARIA labels.

---

Every pull request should improve maintainability.
